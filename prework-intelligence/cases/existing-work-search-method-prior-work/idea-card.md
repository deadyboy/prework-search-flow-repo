# Idea Card

## Original Idea

搜索“搜索已有工作 + 判断是否复用”这个方法本身是否已有成熟方法论。

## One-Sentence Goal

判断 Prework Intelligence 应吸收哪些成熟检索/判断框架，而不是凭空发明。

## Important Constraints

- 不扩展复杂机制。
- 不把商业咨询框架直接纳入 Search Module。
- 不把负证据写成不存在。

## Desired Reuse

- 检索协议。
- eligibility / exclusion。
- snowballing。
- grey-literature quality checks。
- evidence grading。

## Unacceptable Substitutes

- 单一专利 prior-art 流程。
- 单一 systematic review 流程。
- 直接 build-vs-buy 决策模板。

## Search Level

`L3 deep review`
