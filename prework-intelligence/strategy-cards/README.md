# Strategy Cards

Strategy cards guide the Search Module through a specific source class or search pattern in a repeatable way.

They make searches easier to review because they specify what to look for, how to query, what evidence to record, and when to stop.

Strategy cards are not Judgment Module artifacts. They must not output final conclusions such as `放弃不做`, `直接采用`, `接入改造`, `场景定制`, `补齐缺口`, `自研小样`, or `先补证据`.

Each strategy card must contain:

- Purpose
- When To Use
- Inputs
- Source Classes
- Query Templates
- Execution Steps
- Evidence To Record
- Entity Aggregation Rules
- Negative / Failure Searches
- Stopping Rules
- Common False Positives
- Handoff To Evidence Pack
